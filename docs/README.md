# Docs

Notes on how this site is built and why.

- [architecture.md](architecture.md) — how the pieces fit: content pipeline, routing and
  i18n, build and deploy, and how to add a page or a locale.
- [decisions.md](decisions.md) — the choices behind the build, the heuristics we keep
  coming back to, and the assumptions still worth questioning. Each decision notes where
  it stops holding.

These are working documents. When something changes, edit the entry and record why,
rather than letting the docs and the code drift apart.
